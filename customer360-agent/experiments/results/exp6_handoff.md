# 實驗 6：多 agent 交接時的本體檢查

三份題庫中理專／私銀主管的正確計畫 55 份，假設要交給「客戶」角色的 agent；其中 49 份含客戶不可看的指標（共 67 個）。

| 交接方式 | 漏給客戶的指標數 |
|---|---|
| 不檢查直接交接 | 67 |
| 用 Studio 原本的權限規則檢查（沒有總指標繼承） | 1 |
| 用接收方角色重新檢查並去敏（plan.handoff） | 0 |

交接結果：直接通過 6 份、去敏後交接 49 份、擋下 0 份。

Studio 原本規則漏掉的例子：s03 ['securities.total_fee_income']
