# 實驗 5：質疑出現後怎麼處理？

三份題庫中只被質疑（沒有硬擋）的計畫：錯誤計畫 69 份、正確計畫 3 份。

| 處理方式 | 錯誤計畫 → 改對 | 錯誤計畫 → 保守 | 錯誤計畫 → 仍默默答錯 | 正確計畫 → 保持正確 | 正確計畫 → 被改成保守 | 正確計畫 → 被改錯 |
|---|---|---|---|---|---|---|
| warn | 0 | 0 | 69 | 3 | 0 | 0 |
| ask_user | 0 | 69 | 0 | 0 | 3 | 0 |
| llm_recheck／stubborn | 0 | 0 | 69 | 3 | 0 | 0 |
| llm_recheck／compliant | 47 | 0 | 22 | 0 | 0 | 3 |
| llm_recheck／calibrated | 47 | 0 | 22 | 3 | 0 | 0 |
| recheck→再檢查→仍有疑問就問使用者／stubborn | 0 | 69 | 0 | 0 | 3 | 0 |
| recheck→再檢查→仍有疑問就問使用者／compliant | 45 | 16 | 8 | 0 | 3 | 0 |
| recheck→再檢查→仍有疑問就問使用者／calibrated | 45 | 16 | 8 | 0 | 3 | 0 |
| 同上，但只剩錨點缺漏時照答附說明／compliant | 46 | 7 | 16 | 0 | 0 | 3 |
| 同上，但只剩錨點缺漏時照答附說明／calibrated | 46 | 7 | 16 | 3 | 0 | 0 |

- recheck→再檢查：退回模型一次後，對修改後（或堅持的）計畫再跑一次本體檢查；仍被質疑就改成向使用者澄清。
- warn：照原計畫回答，只附上質疑內容。
- ask_user：一律轉成向使用者澄清（保守）。
- llm_recheck：退回模型確認一次；stubborn＝一律堅持、compliant＝一律照改、calibrated＝錯才改（上限）。
