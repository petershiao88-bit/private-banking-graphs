客戶 360 · Semantica 圖譜離線版

只需傳送「客戶360-Semantica圖譜-離線版.html」這一個檔案。
下載到電腦後，用 Chrome 或 Edge 開啟即可；不需 Python、網路或伺服器。
通訊軟體的預覽畫面不一定支援互動，請先下載。

包含四個範圍：
完整圖：146 節點、246 關係
業務圖：104 節點、146 關係
證券圖：29 節點、44 關係
本體圖：43 節點、46 關係

操作：
1. 左側搜尋節點名稱、定義或來源表，點選結果聚焦小圖。
2. 點選畫布節點或名稱，在右側查看定義、直接關係及完整屬性。
3. 雙擊節點或按「展開一層」，加入相鄰節點。
4. 「聚焦所選」只保留所選節點及相鄰節點；「顯示全圖」恢復範圍內全部節點。
5. 拖曳節點調整位置、拖曳背景平移、滾輪或 ＋／− 縮放。
6. 「畫布關係」可篩選連線類型；右側仍列出該節點在目前視圖的全部直接關係。

這是模型快照，保留原始節點與關係屬性；畫面位置為重新排列。
不包含 LLM 問答、即時推理或 Ontology Hub 編輯，也不會寫回來源模型。
本體視圖是原主圖的類別投影，不等同完整 Ontology Hub 屬性編輯器。
分項涵蓋不代表已核定的加總公式，類別對應不代表 RDF 實例斷言。

維護方式：在 semantica-poc 目錄更新 data/*.json 後，執行 build_offline_html.py。
原始介面模板為 offline-viewer.html，請勿修改產出的單檔 HTML。

驗證：Chrome 本機 HTTP 預覽已檢查四視圖、搜尋、空結果、關係篩選、
節點屬性、雙擊／按鈕展開、縮放與置中。資料與原 JSON 逐一比對。
瀏覽器自動化工具限制 file:// 導覽，因此沒有自動測試直接雙擊檔案。
HTML 已內嵌資料與程式，無外部 script、stylesheet、fetch 或 CDN，
並以 Content-Security-Policy 禁止網路連線。
