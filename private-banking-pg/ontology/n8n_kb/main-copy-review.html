KB v3 已發布，使用 typesafe/jev-1.13，實際回傳版本 typesafe/jev-1.13-20260917。每個產品與領域獨立保留 included／uncertain／excluded 分布，probability 為原始 included 機率；confidence 分開保留。沒有跨候選正規化、top-1 截斷或數值門檻；分流使用原生 choice 與歧義攔截，數值門檻尚未校準。詳細證據：本次驗證報告。

KB 的圖譜映射與執行資料庫的實際資料分開看待。目前 ds 業務 schema 可見五張存款來源表；基金所需來源尚未具備。測試確認缺來源時不虛構金額，並不表示基金 AUM 金額已驗證。主流程目前僅配置 AUM registry；KB 本身可接受 Income，但本副本會清楚回覆 Income 路由尚未配置。SQL 節點的來源比對支援目前的明確 FROM/JOIN 與簡單 CTE；它不是完整 SQL parser，複雜 SQL 語法仍需獨立測試。
