# 舊版 v0.2.0 工具

此目錄只保存上一階段的建置與驗證材料，供追溯原始 232 三元組版本。

## 警告

- **不要直接執行 `build_ontology.py`。** 它將 v0.2.0 模型寫死在程式中，會覆寫專案根目錄的本體檔案。
- `verify_ontology.py` 會與 `reference-graph.json` 的舊參考圖比對；模型合法擴充後若未更新基準，失敗是預期結果。
- `validation.json` 是上一階段的驗證紀錄，不代表通用 RDF 解析、完整 OWL 推論或目前版本持續通過。

目前已由上層 `../build_ontology.py` 及專案根目錄 `build-config.json` 取代。新建置器讀取有效 TTL，不使用本目錄寫死的模型或舊參考圖。原公司通聯模組已封存，勿重跑本目錄工具。
